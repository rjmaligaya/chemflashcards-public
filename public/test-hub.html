Tester hub

For the research team. Open any page below to try it out, and leave edit requests right on the page.

This is a safe sandbox. Each page you open gets a brand-new test identity, so nothing you do here is mixed in with real participant data. You can click around, finish or abandon a session, and start over as many times as you like.
  1. Pick an option below (most testing can stay on Option 1 — it just changes which word-set is which).
  2. Click “Open” on any page. It opens with a fresh test identity, so you’ll never be told a session is “already done.”
  3. To request an edit: on any page, use the dark Tester bar in the bottom-right corner. Click “✎ Request edit”, then click anything you’d like changed and type a note. Add as many as you want, then press Send.
  4. Want to see a session’s later screens without doing every question? Open it, then use the bar’s ↻ Restart or jump via Pages any time.
Counterbalance:

Each “Open” creates a throwaway test id (tagged dev_mode) and is filtered out of analysis. Edit requests you send are collected for the study coordinator to review in Admin / review. This page is not linked anywhere public.
